# Company Move

A transpo racing game: nine Teamsters, five cities, every race under call time. Made for film crews, by one.

**Play it:** https://ncoker70-pixel.github.io/CompanyMove/

Works in any phone browser. Turn your phone sideways to drive. Thumb on the left to steer, the big button on the right to drift, ITEM when you've got one. Add it to your home screen and it opens full screen.

The game is one file (`index.html`), built from the source in the main project.
